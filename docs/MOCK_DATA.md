# Simulated data

Generated by `scripts/gen_mock.py`. Everything below is simulated; nothing else in the database is.

`SEED = 42`. Every value comes from an MD5 hash of the seed and the course code (never Python's salted `hash()` or a random generator), so re-running the script produces identical rows.

Last run: 208 offerings for 170 recommendable and 38 undergraduate prerequisite courses, and 170 workload rows.

| Field | Table | Why simulated | How generated |
|---|---|---|---|
| Term offered | `mock_offerings.term` | The public catalog lists no schedule; the interface needs one to show offerings. | Core courses in 2027SP and 2027FA; seminars in 2027FA; other courses 2027SP when the last digit of the code is even, else 2027FA. Also generated for undergraduate courses named in a recommendable course's prerequisites, so the readiness path hint can name a term. |
| Meeting days | `mock_offerings.days` | The public catalog lists no schedule; the interface needs one to show offerings. | Alternates MWF and TR in course-code order. |

| Seats | `mock_offerings.seats` | Enrolment caps are not public. | 20 to 90, from an MD5 hash of SEED, term and code. |
| Difficulty | `mock_workload.difficulty` | No public difficulty ratings exist for these courses. | 2 to 5, from an MD5 hash of SEED and code. |
| Hours per week | `mock_workload.hours_per_week` | No public workload data exists. | difficulty x 3 plus 0 to 3, from an MD5 hash of SEED and code. |
